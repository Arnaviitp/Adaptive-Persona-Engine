# Persona-Drift-Detector

The Adaptive Persona Engine is a local, privacy-first system designed to track user mood and tone shifts over time, process daily intents entirely offline, and resolve contradictory context points generated by long-term user logs (RAG).

## Features

The repository is broken down into three core modules inside the `src/` directory:

### Part 1: Adaptive Persona Engine (`src/part1_drift_detector.py`)
Tracks how a user's mood and tone change across days.
- **Drift Timeline:** Outputs a sequential timeline mapping the user's emotional state day by day.
- **Trigger Detection:** Identifies the precise events, topics, or people that caused the shift in the persona.

### Part 2: Offline Intent Classifier (`src/part2_intent_classifier.py`)
A lightweight NLP classification engine built for environments with strict local-only requirements.
- **Fast & Small:** Uses a highly optimized Scikit-learn pipeline (`TfidfVectorizer` + `LogisticRegression`). Model size is < 0.05 MB.
- **Offline CPU Inference:** Makes predictions under ~2ms on a standard CPU.
- **Categories:** Accurately sorts messages into: `reminder`, `emotional-support`, `action-item`, `small-talk`, or `unknown`.

### Part 3: RAG Conflict Resolver (`src/part3_rag_resolver.py`)
Handles hard retrieval problems where retrieved context blocks present contradictory facts.
- **Heuristic Ranking:** Ranks retrieved chunks by calculating a score based on a mix of recency and emotional weight.
- **Contradiction Flagging:** Flags semantic contradictions (e.g., loving vs. hating a subject) before generation.
- **Merged Synthesis:** Safely merges the knowledge, allowing more emotionally charged and recent facts to override older, outdated contexts.

## Installation

Ensure you have Python installed, then install the necessary dependencies for the machine learning modules:

```bash
pip install scikit-learn joblib
```

## How to Run

You can test each module independently. They all contain built-in sample data and demonstrations.

Run the Drift Detector:
```bash
python src/part1_drift_detector.py
```

Run the Intent Classifier (will automatically train and save the offline model if it doesn't exist):
```bash
python src/part2_intent_classifier.py
```

Run the RAG Resolver:
```bash
python src/part3_rag_resolver.py
```
